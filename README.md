# DoveWAI Language

DoveWAI Language is an experimental language project within the DoveWAI platform.

Public development record established: 2026-08-13.

Current public direction:
- portable execution across different classes of devices
- explicit policy and resource-aware execution
- small, extensible language core
- adaptive use of available compute

Implementation details, research methods, internal algorithms, and unreleased runtime/compiler work remain private while the project is under active development.
