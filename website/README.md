# DoveWAI Website

Initial public-facing DoveWAI website for Cloudflare Pages.

## Cloudflare Pages

Use these settings:

- Repository: `DoveWAI/Dovewai-language`
- Production branch: `main`
- Framework preset: None
- Build command: leave empty
- Build output directory: `website`
- Custom domain: `dovewai.com`

The website is intentionally isolated under `website/` so it does not interfere with the language project files in the repository root.

## Public status

The site describes DoveWAI as being in active development and distinguishes current development work from longer-term product direction.

## Pre-launch checks

- Connect the repository to Cloudflare Pages.
- Set the output directory to `website`.
- Attach `dovewai.com` and confirm the `www` redirect.
- Review Privacy and Terms against the final legal entity and production configuration before wider commercial launch.
- Add an official `@dovewai.com` contact address once the desired mailbox is confirmed.
